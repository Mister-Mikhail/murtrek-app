# MURTREK для Android

Тонкая оболочка: сайт murtrek.com в WebView, скачивание файлов, окно оплаты и обновление приложения изнутри.

## Как поставить
1. Откройте на телефоне страницу «Releases» этого репозитория и скачайте файл `murtrek-N.apk` последней версии.
2. Разрешите установку из браузера (Android спросит сам) и установите.
3. Дальше обновления приходят в самом приложении: при запуске оно проверяет новую версию, предлагает обновиться и ставит её поверх.

## Как выходит новая версия
Каждый коммит в `main` собирает GitHub Actions (`.github/workflows/android.yml`): номер сборки = номер запуска, выкладывает APK в Releases. В описании релиза строки `MURTREK_VERSION_CODE` и `MURTREK_SHA256`, по ним приложение сравнивает версии и проверяет файл.
Если сборка упала, хвост журнала лежит в ветке `ci-logs`.

## Ключ подписи
`app/murtrek-test.p12` общий тестовый ключ: тестовые сборки ставятся друг поверх друга. Для магазина будет отдельный ключ, он в репозиторий не попадёт.
